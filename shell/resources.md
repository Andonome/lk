- `mapscii.me` is an interactive terminal map.
    1. Install telnet.
    1. `telnet mapscii.me`
- [Over the Wire](https://overthewire.org/wargames) teaches bash with small challenging you can do over `ssh`.
- [Doom](https://github.com/wojciech-graj/doom-ascii)!  Try it online with `telnet doom.w-graj.net 666`.
- [Defuddle](https://defuddle.md) returns a page in markdown:
    * `curl -s defuddle.md/theskullery.net/`
    * `curl -s defuddle.md/enworld.org/threads/the-rise-and-fall-of-evil-genius-games.702617/`
